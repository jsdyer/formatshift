Sources, date meanings & privacy

MusicBrainz, with context

Community-maintained core metadata (CC0). A release is one particular edition; a release group brings editions together. Format belongs to each medium, so one box may contain CD, vinyl and Blu-ray.

Dates are reported edition dates, not recording dates or the date we retrieved the record. Partial dates stay partial. Missing dates and countries stay unknown. Check the original record if a date or format looks unusual.

Initial records are a deliberately selected set, not a representative sample. Live artist browsing is paged and may include compilations; loaded records are not the entire artist catalogue.

Your session

Searching sends your artist name or MusicBrainz ID and your IP address to MusicBrainz. Filters, comparisons and imported files stay in this tab. Receipts contain the visible collection's metadata and capture time. Downloads happen only when requested.

No audio, lyrics, artwork, accounts or API keys are collected. Local imports are never uploaded. A request timestamp may be stored to coordinate API pacing across tabs; searches and results are not saved on this device.
